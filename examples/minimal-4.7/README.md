# Minimal Godot 4.7 project

A small, real project used to accept this plugin on a live engine. Open it with Godot 4.7 (or point the agent at the folder) and the seventeen `godot_*` tools have something to drive.

It is deliberately tiny and deliberately *ordinary*: a `Node2D` root with a `Label`, a `CharacterBody2D` that reads `ui_left`/`ui_right`, and a `Game` autoload the scripts call — so the tool surface gets exercised against the things that actually trip plugins up:

- an **autoload referenced from another script** (`Game.add_score`), which is what makes a naive `--check-only --script` validator report a false `Identifier not found`;
- a **live property** (`Main.probe_calls`) reachable from `godot_command call_method` / `get_property` while the game runs;
- a **main scene** that quits on `ui_cancel`, so a windowed run is closable without killing the process from outside.

```
project.godot                 # main_scene + Game autoload + the McpInteractionServer autoload, 640x360
scenes/main.tscn              # Main(Node2D) -> Label, Player(CharacterBody2D) -> Shape + Marker
scripts/main.gd               # prints the engine version, calls Game.add_score(5), add_probe_calls()
scripts/player.gd             # moves on ui_left/ui_right, calls Game.add_score(1)
autoload/game.gd              # the Game autoload: score + add_score()
autoload/mcp_interaction_server.gd   # vendored copy of plugin/mcp_interaction_server.gd (the in-game TCP server)
```

`autoload/mcp_interaction_server.gd` is a copy of `plugin/mcp_interaction_server.gd` so the project is playable on its own. You do not have to keep it: `godot_run_project` installs the vendored copy automatically when the autoload is missing (that is the path this plugin's `scripts/smoke.mjs` exercises), so a project without it works too.

## Run it

```sh
# headless: boot the main loop, print one line, exit
godot --headless --path . --quit-after 3

# windowed, driven from a DSH session
godot_run_project            # tool: launch with the debugger, wait for 127.0.0.1:9090
godot_command get_scene_tree
godot_command call_method {node_path: "/root/Main", method: "add_probe_calls", args: [1]}
godot_screenshot
godot_stop_project
```

`.godot/` is generated by the engine on first open and is git-ignored.
